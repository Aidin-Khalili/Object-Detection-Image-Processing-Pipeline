# Object Detection with Classical Image Processing

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) ![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?logo=opencv&logoColor=white) ![scikit-learn](https://img.shields.io/badge/scikit--learn-F7931E?logo=scikitlearn&logoColor=white) ![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

A complete classical computer-vision pipeline (Multimedia course, B.Sc. in Computer Engineering): **image enhancement → segmentation → representation & description → classification**.

![Sample result](https://github.com/Aidin-Khalili/Multimedia-Object_Detection/assets/91956465/1ec2106b-1007-4914-aad1-b625aa8b7b96)

## Pipeline

- **Enhancement:** spatial and frequency-domain filtering, morphological operations
- **Segmentation:** separating objects from the background
- **Representation & description:** shape and region features, feature selection
- **Classification:** SVM classifier on the extracted features

## How to run

```bash
pip install numpy opencv-python scikit-learn matplotlib
python Code.py
```
